## 1. 规则版本与适用范围

1. 新版结算规则记为 `settlementRules = 2`，在新建轮次时写入，并在封盘时冻结进快照。未带该字段的旧轮次（含在途局、已封盘未结算局、已落账局）一律沿用模块 05 的旧倍率结算，规则与结果不变。
2. 本规则适用于**账号版（同局多人）的新局**。匿名 V2.1 整局体验是已冻结的发布基线，继续用旧倍率结算，不在本卡改动范围。同一服务内只允许一种结算口径，由快照上的规则版本决定，不由当前代码版本决定。
3. 新建账号服务时按本规则开局；已存在的账号 SQLite 不足本轮新开范围的，在途及后续轮次仍带旧口径，保持续接一致。结算在回放结束后、每轮每账号至多一次，与余额和个人历史在同一事务写入。规则版本随结果和战局包落库，供回查当时依据。

## 2. 奖池口径

1. 奖池只由**玩家已确认的实扣**构成。每账号在胜方的实扣记作 `s胜`，在败方的实扣记作 `s败`；全体账号胜方合计 `R = Σs红`、败方合计 `B = Σs蓝`。
2. 系统投点（每轮参照下注）**只用于强化阵容**，不计入 R、B，也不参与分配。
3. 同一账号可同时押红蓝，其红、蓝实扣分别计入 R、B。
4. 玩家未确认（余额不足、已截止、重复请求被拒）的金额不计入奖池。

## 3. 结算公式

记赛果 `W ∈ {red, blue, draw, void}`，账号 a 的红蓝实扣为 `r_a, b_a`，`R = Σr_a`、`B = Σb_a`。

1. **退款场景**：`W` 为 `draw` 或 `void`，或 `R = 0` 或 `B = 0`（只有一边有玩家实扣，即使对侧有系统参照投入）——每个账号 `credit_a = r_a + b_a`，全额退回已确认投入。
2. **正常奖池**（`W` 为红或蓝，且 R、B 均大于 0）：
   - 败方池 `L = B`（红胜）或 `R`（蓝胜）；胜方池 `P = R`（红胜）或 `B`（蓝胜）。
   - 抽成 `k = floor(L × 5 / 100)`，向下取整，不发给任何账号。
   - 可分配 `D = L − k`。
   - 对每个 `s_a > 0`（该账号在胜方的实扣）的账号：原始份额 `D × s_a / P`，基础份额 `q_a = floor(D × s_a / P)`，余数 `m_a = (D × s_a) mod P`。
   - 余额点 `e = D − Σq_a`。按 `m_a` **从大到小**排序给前 `e` 个账号各加 1；余数相同按首次确认顺序（库内 rowid）升序，再按账号 UID 升序，保证确定性。
   - 账号入账 `credit_a = s_a + q_a + (前 e 名则 +1)`，即**拿回本边本金**＋分得败方池。败方一侧实扣不再退回。
3. 净变化 `net_a = credit_a − (r_a + b_a)`。
4. **守恒**：`Σcredit_a + k = R + B`，即到账合计加抽成等于全体玩家实扣，余数排序不改变总额。

整数运算全程用 BigInt 做乘法与取模，避免大点数下溢出或浮点误差。

## 4. 结果、历史与导出

1. 每账号结果保留现有字段（赛果、格数、双方实扣、总投入、`rates`、入账、净变化、结算后余额、回执），新增 `settlementRules = 2` 与 `pool = { red, blue, winnerPool, loserPool, rake, distributable, principal, share }`（均为该账号可见的奖池口径与本人本金、分成）。
2. `rates` 仍是封盘时锁定的展示倍率，供界面与导出参考；**新版入账不再由它计算**，界面在 `settlementRules = 2` 时改按奖池明细展示。
3. 历史与完整 `bet_data` 导出包含 `settlementRules` 与 `pool`，可逐笔回查本人实扣、抽成和分配依据；同轮重复读取、双标签重进、进程重启均复用同一次落账。
4. 旧局结果不带新增字段，导出与回放保持旧结构。

## 5. 验收场景

| 场景 | 预期 |
| --- | --- |
| 双账号各押 100，红胜 | 红账号入账 195（本金 100＋分成 95），蓝账号 0。 |
| 单账号红蓝各押 100，有胜负 | 入账 195、净变 −5；两边都有玩家实扣按正常奖池结算。 |
| 单边玩家实扣 100，对侧仅系统参照 100 | 全额退回 100。 |
| 平局、战斗作废 | 按已确认实扣全额退回。 |
| 多账号非整除分配 | `Σ入账 + 抽成 = Σ实扣`；余数按余数降序、确认序与 UID 兜底分配。 |
| 同请求重试、封盘后新请求 | 重试回原回执不多扣；封盘锁规则，截止后拒新注。 |
| 旧版在途局续接 | 无 `settlementRules` 的轮次按旧倍率结算，结果与余额不变。 |
| 重启与历史/下载 | 重启后余额、历史一致；下载包按同一规则复现到人账与净变化。 |
