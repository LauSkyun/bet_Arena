# 竞猜竞技场参考审阅与原型建议

**讨论稿 · 2026-11-22**。每轮从上下双方各一座主基地开始。玩家在下注阶段为支持方触发随机扩建或升级，封盘后观看自动交战。首版建议限时按占格数判胜。

本版在相邻扩建、占格翻色和逐个补兵的基础上，补齐开局随机阵营、跨阵营抽取兵种和各兵种的存活上限。#game研讨会 msg=54151dd6 #game研讨会 msg=0d16f491

## 一轮怎么玩

| 阶段 | 玩家看到什么 | 原型规则建议 |
| --- | --- | --- |
| 下注 | 同屏看到上下两队及其主题、当前兵营与兵种、双方投入、自己已投、倒计时和金额档位 | 玩家每轮最多选择一方，可在封盘前追加。每累计跨过一个金额门槛，支持方触发一次随机建造或兵种升级，立刻显示具体变化。累计投入与剩余距下个门槛的差额都可见。 |
| 截止 | 下注入口关闭，短暂展示双方最终配置 | 冻结有效下注和战斗开局。只认截止前已确认的下注，截止时或之后提交的下注不扣点。同一局的所有观战者看到同一场战斗。 |
| 战斗回放 | 在同一张棋盘看自动出兵、交战和地块变色，常驻剩余时间与占格数 | 用封盘配置生成这轮战斗。播放只读，重进从当前进度接续。观战者的断线、退出和播放速度均不改变赛果。 |
| 下注结果 | 胜负或平局、最终格数、本人支持方与积分变化 | 测试用虚拟积分先按固定结果核对。赢则退回投入并加等额积分，输则扣去投入，平局退回投入。未下注只看结果。每笔结算一次，重进仍可读结果。 |
| 下一轮 | 短结算结束后回到新一轮倒计时 | 清空上一轮战场、投入和建造升级记录，积分在同一场试玩中延续。 |

**同一阵营的累计投注额决定触发次数。** 每跨过一个金额门槛，按当时可用的建造或升级效果抽取一次。同一笔跨多个门槛时逐次结算，每次重新检查候选。例如每 10 点触发一次，先投 6 点再投 14 点，与一次投 20 点都触发两次。门槛值仅用于说明。

首轮试玩用一张对称棋盘和少量预设投注。双方各有一座主基地，下注生成的第一座兵营从主基地旁开始。开战时双方各带 3 名数值相同的基础兵，使零下注也能完成一轮。玩家可支持上方、下方或跳过。封盘时记录双方最终战力，战斗期间沿用这一开局。

`游戏流程.mp4` 约 61 秒。约 4 秒看到投入档位，约 7–11 秒看到投入飘字和强化变化，约 16 秒看到单位强化详情。结尾仍在倒计时。`进入界面时处于战斗阶段.jpg` 提供了中途进入时的观战入口参考。封盘与结算顺序以 kaikai 的描述为依据。保险弹窗、回报率的更新算法与原参考游戏的角色、美术和战斗都留在参考范围。

## 扩建、占格与出兵

### 1. 主基地与相邻扩建

- 每轮开局，红蓝各有一座主基地，位置与初始领地由地图对称配置。每座主基地、兵营各占一格。地图保证主基地旁至少有一个合法建造格，并预留通路与各建造格的出兵口。摆满后仍能从两侧通往战场。
- 第一次强化从己方主基地的上下左右合法空格中随机选一格生成兵营。后续建造从己方任一现有建筑的上下左右合法空格中随机选一格。每个合法格只进一次随机池。合法格为己方可建区域内、允许摆放兵营的未占用格。
- 建造和升级在下注阶段即时显示。每座新建兵营按下节规则抽取一个兵种，本轮固定生产该兵种。首座兵营生成后，每次触发在当前可用效果中抽取。建造到上限或无合法邻格时只抽升级。每次升级提高被抽中兵营的出兵等级，达到等级上限后移出升级候选。两种效果都用尽时显示「本轮强化已满」，后续有效下注仍参与本轮积分结算。

### 2. 兵营数量上限

- 兵营上限等于该阵营开局可用于摆放兵营的格数。主基地格、预留通路和出兵口排除在这些格子之外。每格最多一座建筑。即使未达到数量上限，也只有存在合法邻格时才能继续扩建。
- 可建区域固定到本轮结束。战斗中的占格翻色只更新战场归属和分数。封盘冻结建筑布局，战斗中被摧毁的建筑停止运作。

### 3. 小兵占格

- 开战时，双方初始领地内的普通可通行格显示各自阵营色，中间区域从中立开始。小兵进入普通可通行格时，格子立即变为该小兵所属阵营的颜色。红兵进入蓝格翻红，之后蓝兵进入同一格翻蓝。格子在小兵离开后保留颜色。中立格可按同一规则首次占领。
- 如果双方在同一结算时点进入同一格，原型暂定该格保留进入前的归属。先后可区分时以最后进入的一方为准。可建格、主基地格、兵营格和被毁建筑留下的废墟保持独立标记。限时计分只数已占领的普通可通行格。

### 4. 开局阵营与兵种抽取

- 每轮开启下注前，上方红队和下方蓝队分别等概率抽取人族、神族或虫族主题，各抽一次，允许双方同主题。界面同时显示队伍颜色和主题，部队归属和占格颜色按红蓝队伍判断。
- 每座新兵营独立抽取兵种。先抽兵种来源主题，己方主题权重为 **50%**，其余两族各 **25%**。再独立抽轻型、中型、重型，原型权重分别为 **50%、35%、15%**。两次结果共同确定表内兵种，每座兵营都可抽到任意主题和档位，允许重复。
- 同档兵种首版共用战斗数值和攻击方式，先用轮廓或图标区分来源主题。这样可以先验证混编观感、数量差异与占格表现。

| 兵种来源 | 轻型近战，存活上限 10 | 中型近战，存活上限 5 | 重型远程，存活上限 3 |
| --- | --- | --- | --- |
| 人族 | 巡地兵 | 护阵步兵 | 长弩手 |
| 神族 | 闪步卫 | 石环卫 | 棱光射手 |
| 虫族 | 掘行虫 | 扣甲虫 | 脊弩虫 |

### 5. 兵营出兵与补员

- 每座兵营按所产兵种的存活上限计数。两个同兵种兵营各有一份额度，开战时的 3 名基础兵单独计数。兵营升级只提高出兵等级，存活上限仍取该兵种配置。以 6 个可建格的示例计算，一方最多同时有 63 名单位，包括 6 座全抽到轻型兵的兵营和 3 名基础兵。
- 原型出兵间隔为 **0.5 秒**。开战后经过首个间隔产出第一名，此后每个间隔至多产出一名，达到上限即暂停。满员后出现空缺，经过一个完整间隔补一名。若同时少两名，两个间隔各补一名。出口暂时无法出兵时，在下一间隔再试。兵营被毁立即停产，已产出的小兵继续作战。

### 胜负先用占格数

- **限时占格（首版建议）**。到时按最终占格数判定，多者胜，同数平。主基地被摧毁后战斗仍按限时规则结算。回放显示实时格数和比赛剩余时间。
- **全建筑摧毁（第二版对照）**。率先清空敌方全部建筑的一方胜，同时清空为平。观战目标更直观，需要处理建筑藏角落和剩余部队打不到建筑的问题。保留终止时限，届时都未达成则平。若后续尝试混合胜负规则，再明确定时终止和同一时点清空建筑的优先级。

## 原型验收场景

| 场景 | 预期结果 |
| --- | --- |
| 主基地在 A11，假设 A12 和 A21 都是合法空格 | 第一座兵营只能在 A12 或 A21 随机生成。若建在 A12，A13 会进入下一次的候选，前提是它也符合可建条件。隔开的 A33 仍不可选。 |
| 某阵营起始有 9 个领地格，其中 1 格是主基地，另有 2 格用于通路和出兵口 | 最多能摆 6 座兵营。第 6 座生成后，下一次强化只从可用升级中抽取。 |
| 红兵走入普通蓝格，离开后蓝兵再走入 | 先翻红并从蓝方扣一格、给红方加一格。红兵离开仍记红方，蓝兵随后进入时翻蓝并反向更新分数。 |
| 两方同时进入同一普通格 | 保留进入前的归属，双方分数不变。 |
| 红队抽到虫族主题，先后建两座兵营 | 首座可抽到人族巡地兵，第二座可抽到神族棱光射手。两种兵在战场上都属于红队。 |
| 两座兵营都抽到中型兵，其中一座满员后同时损失两名 | 该兵营的存活数依次为 3、4、5。出口可用时，每隔 0.5 秒补 1 名，另一座兵营按自己的额度出兵。 |
| 兵营在补员的等待期间被摧毁 | 取消后续补员。已出场小兵继续战斗。 |
| 封盘时双方只有主基地 | 对称基础兵入场，战斗到时照常按最终占格数结算。 |

## 试玩怎么验证

- 让玩家用三轮测试积分体验支持上方、下方和中途观战。记录能否自行完成下注并指出具体是新增了兵营还是升级了出兵。
- 用相同开局配两组不同投入脚本，确认额度改变强化次数且小投入方仍可能获胜。用相同投入配两组不同随机结果，确认差异能从画面上看出来。
- 核对封盘同时点击、无人下注、同格数平局和回放中重进四个边界，确保每轮只有一个战斗结果和一份积分结算。观察玩家能否仅凭战场和格数解释胜负，以及结算后是否主动参与下一轮。

**审阅范围**涵盖玩法目录的四张图和视频抽帧、战斗目录的九份工作簿（含两份 UI 表的内嵌图片）和资源目录原始文件。即时生效、限时计分和积分结算沿用原型假设。主题权重、档位权重、兵种上限、出兵间隔和地图配额均为试玩初值。
