# SC 兵种分版计划 · V2.1 地面战 / V2.2 空地战

2026-11-24 · #game研讨会:#36 · 依据 kaikai 的分版决定和 [27 个单位的数值提案](sc-roster-proposal.md)。下文是实施顺序与验收预期。两个版本各自交付一局可下注、可观战、可结算、可导出重演的独立试玩。

## 首次可用的单位

| 种族 | V2.1 地面战 · 19 个 | V2.2 新增空军 · 8 个 |
|---|---|---|
| 人族 | 陆战队员、火蝠、幽灵、秃鹰车、攻城坦克、歌利亚、医疗兵 | 幽灵战机、战列巡洋舰 |
| 神族 | 狂热者、追猎者、黑暗圣堂武士、执政官、金甲虫、巨像 | 侦察机、航空母舰、虚空辉光舰 |
| 虫族 | 小狗、刺蛇、猛犸、蟑螂、爆虫、遁地兽 | 飞龙、守护者、吞噬者 |

**陆战队员、幽灵、歌利亚、追猎者、执政官、刺蛇**在 V2.1 先完整承担对地职责，V2.2 给同一单位开放对空目标。医疗兵先治地面友兵，V2.2 增加空军友兵。守护者虽仅打地面，飞行移动与免受纯对地攻击决定了它必须随 V2.2 上。吞噬者的首次出场与空中目标同版。

## V2.1 · 一局完整的地面战

| 顺序 | 实现与可交付结果 |
|---|---|
| 1. 抽营、出兵、封盘 | 在 `roster.mjs`、`profiles.mjs` 引入独立的 SC 地面配置。按版本筛池，再抽来源种族与当前可用的品质。原型 `drawUnit` 先抽轻中重、`profileUnit` 按档替换名称的路径继续服务旧局。新配置按单位编号冻结射程、伤害、出兵节奏、每营上限、步频和技能；品质只控制抽取。首营须是能对地的绿色地面攻击兵，候选为人族陆战队员／秃鹰车、神族狂热者、虫族小狗／蟑螂。第二座起，某族缺少品质时按剩余权重归一化，例如 V2.1 人族只有绿蓝紫，相对权重为 45∶35∶15。 |
| 2. 地面移动与普通攻击 | 复用 `battle.mjs` 六边形地面寻路、建筑阻挡、锁定和半秒节拍，在合法移动前检查本兵的移动间隔。按单位自己的攻距与攻速出手。先跑普通单体从出兵到占地、拆营、拆基地的全链路，验证近战和远程能在各自距离发挥。 |
| 3. 范围、自爆和治疗 | 在同拍伤害汇总处增加火蝠扇扫、巨像直线、金甲虫和执政官溅射、爆虫自爆，并逐目标记录实际命中。医疗兵向友军选目标。建议同拍以行动前存活者出手，合计伤害与治疗、封顶最大生命，再判死；爆虫触发后必消耗，自爆只结算一次。保留主目标建筑全额直击及兵营、基地的原有胜负规则。 |
| 4. 棋盘、回放与整局 | `board-display.mjs` 接入地面 19 个双字营标／单字兵标。格子详情显示实际命中对象、伤害或治疗，群伤箭头覆盖实际受击位置。冻结本轮配置随战斗导出，刷新、重演、结算和上下镜像分别验证。 |

**可并行的工作。** 单位表、棋盘字标与固定局面用例可同时准备。范围效果和治疗可在普通攻击结构上并行，合回同一拍后再验死亡和胜负。继续沿用下注累计建营／强化、按轮保存门槛及建筑血条。

**V2.1 验收局面**

- 封盘检查每族可出兵清单，19 个均可从合法路径建营，首营对地可进攻。小狗营开战 3 秒产两只；陆战队员同一时点产一名，相距 3 格即可命中。在空地上各走三步，快、中、慢单位的步间隔分别为 0.5、1、1.5 秒。
- 把 3 名敌兵排在巨像的同一直线上、另 1 名放线外，一级命中分别扣 30、30、30、0。金甲虫主目标／邻兵扣 100／50。爆虫接近后主目标扣 68、邻兵 34，自身当拍消失；另验火蝠身前扇区与身后单位。
- 一级医疗兵每秒治疗 12，友兵 70/100 在一次治疗后为 82/100。若同拍另受伤 10，则为 72/100；无伤员时保持待援。用镜像一局核对实际命中、领地分、基地血线与余额，导出重演得到同一胜方。

## V2.2 · 空军、地面对空和混战

| 顺序 | 实现与可交付结果 |
|---|---|
| 1. 分开飞行、索敌和占地 | 给战斗单位区分所属层（空／地）和可命中的层。飞行按六边形距离在界内移步，可越过建筑与废墟；地面仍走现有路径。规划追击、保留旧锁、实际出手、范围的每个目标都使用同一目标层过滤。`applyOccupancy` 仅接收存活地面兵，飞越、悬停、出兵均不翻地，不干扰同格地面占领。建筑属于地面目标，基地反击可选两层敌兵。 |
| 2. 首次空地交战 | 先用陆战队员、狂热者、守护者、吞噬者形成最小验证局。守护者可对地兵和建筑开火，遇到敌机时没有对空武器；吞噬者只追打空军，无空军时不转打建筑。随后启用六种地面两用兵的对空攻击和医疗兵对空治疗，接入八种空军各自的生产配置。 |
| 3. 空军专属攻击 | 飞龙逐跳筛选合法目标并按 20／10／5 衰减。虚空辉光舰同目标持续命中按 12／15／18 封顶，换目标重置。航母由表现用子机交替出手，每个射击间隔整舰只结算一次；子机不占格、不另占兵营名额。吞噬者溅射只影响空中层。 |
| 4. 混编读图和旧局兼容 | 同格分队伍、兵种、空地层统计，详情能辨出被哪种攻击击中。选中空军展示射程；范围内的地面建筑是否受击取决于武器。V2.2 新轮开放 27 个；仍处于 V2.1 的轮次按封盘版本重演，保留当轮血量、赛果和余额。 |

**V2.2 验收局面**

- 同格放地面狂热者与空中侦察机。敌方吞噬者命中侦察机扣 36、相邻敌机扣 18，狂热者扣 0；敌方狂热者只能击中地面目标。撤掉敌机后，吞噬者对地兵、兵营及基地均无命中。
- 守护者越过阻路兵营上方的格子，独自经过敌方计分格时比分不变；同格友方地面兵可以翻格。让守护者停在敌基地 3 格内，基地每秒反击 12，守护者能还击。用医疗兵验证对空治疗，建筑仍不在治疗候选内。
- 飞龙一次弹射不重复命中；虚空辉光舰换目标后第一击恢复 12；两架子机表现下的一级航母每 0.5 秒合计只打 12。固定阵容红蓝互换并回放，从每一处命中追溯到血量，再核对终局比分。

## 交付与回退

采用 #35 已测试的下注门槛候选作为开发起点，独立复核结果留在原卡。V2.1、V2.2 分别保留配置版本、规则版本、提交和试玩入口。每版先跑既有回归、固定局面和实际下注整局，再交独立验收。V2.2 的直接回退点是届时验收通过的 V2.1 提交；兵种更新前的远端标签为 `arena-before-sc-roster`（`61c5f1b`），100 点可配置候选为 `82d3ec8`。切回时可重开对应入口，已封盘局使用原阵容和规则重演。
