# 棋盘兵种字标与实际射程

#game研讨会:#30 · [界面需求 v0.4](requirement.md) · 基于 #29 首批兵种候选 `05964d6`。独立试玩 `http://127.0.0.1:8765/arena-board-units/`。

## 界面与数据

`board-display.mjs` 定义单字映射、按格分组和命中线绘制。棋盘与两队兵营清单共用同一映射。基础卒为「卒」，竞技场人／神／虫三族依次为「巡护弩」「闪石棱」「掘甲脊」，SC 为「跳狂枪」。同一阵营的同名同射程士兵显示一组，每格最多直接排四组；超过四组时显示前三组和省略号，在棋盘下逐格列出完整阵容。

`battle.mjs` 在攻击通过冷却与距离检查后、扣血和移除阵亡单位前，记录起点、终点、阵营、名称与射程。双方同拍阵亡或建筑被摧毁仍有命中记录。每半秒换为新一拍的记录。相同阵营、相同起止格的线画一次。格子详情可区分其中各兵种的实际命中去向。只查看格子和范围的操作不参与模拟或落账。
