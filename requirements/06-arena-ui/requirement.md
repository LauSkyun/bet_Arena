## 1. 入口与共通布局

打开 H5 原型后进入当前轮的竞技场界面。战场保持上下布局，红队在上，蓝队在下，队伍名称和主题与颜色同时显示。棋盘旁在下注和封盘期显示开局占格数，回放期随占领变化更新。顶部展示当前阶段、可取得的阶段倒计时和测试余额。页面恢复后同步该轮的确认状态。玩家可展开「下一轮时长设置」，查看本轮和下一轮的时长，填写并保存下一轮配置。输入和生效规则见[轮次与阶段](../01-core-loop/requirement.md#3-下一轮时长设置)。

## 2. 阶段展示与操作

| 阶段 | 必须显示 | 玩家操作与反馈 |
| --- | --- | --- |
| 下注 | 红队信息栏在棋盘上方，蓝队信息栏在棋盘下方。各栏显示[实时回报率](../05-settlement/requirement.md)、本人投入、队伍总投、当前建筑和兵种及强化进度。表单显示当前选中的提交队伍 | 选择队伍并填写投入点数后提交。成功刷新余额和累计，并在对应建筑格显示新增兵营或升级。排队确认期间可见等待态，失败后给出原因并保留已确认状态。 |
| 封盘 | 封盘状态、最终的两队配置、有效投入及[锁定回报率](../05-settlement/requirement.md) | 下注入口关闭，查看最终配置。 |
| 战斗回放 | 同一轮棋盘、目前占格数、剩余时间、兵营出兵与战场变化 | 只读观战。可读出哪一方占了哪些格，以及两队当前分数。 |
| 下注结果 | 胜负、最终格数、本人在两队的投入、积分净变化、结算后余额和下一轮倒计时。本人在胜方有投入时显示实际用于入账的锁定倍率 | 自动展示已落账结果。作废显示作废和返还；未参与显示观战结果。 |

建造与升级反馈显示队伍、事件和发生位置。普通格翻色表示战场占领，建造专用格使用固定样式。下注阶段分别显示本人投入和系统参照投入。阵营已满时，强化进度改为显示已满，提交后提示未新增战力。进入下一轮后，可查看最近完成的一轮结算摘要。

## 3. 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 正常下注成功 | 看到对应阵营投入和余额变化，可识别新增／升级的兵营 |
| 提交时恰逢封盘 | 界面转封盘并显示真实确认结果，无法再发起下注 |
| 中途进入回放 | 显示同轮当前棋盘、实时格数和剩余时间 |
| 平局或失败 | 结果页的投入、净变化和余额与本轮实际落账一致 |
