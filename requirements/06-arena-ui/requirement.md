## 1. 入口与共通布局

打开 H5 原型后进入当前轮的竞技场界面。战场保持上下布局，红队在上，蓝队在下，队伍名称和主题与颜色同时显示。棋盘旁在下注和封盘期显示开局占格数，回放期随占领变化更新。顶部展示当前阶段、可取得的阶段倒计时和测试余额。页面恢复后同步该轮的确认状态。玩家可展开「下一轮时长设置」，查看本轮和下一轮的时长，填写并保存下一轮配置。输入和生效规则见[轮次与阶段](../01-core-loop/requirement.md#3-下一轮时长设置)。

## 2. 阶段展示与操作

| 阶段 | 必须显示 | 玩家操作与反馈 |
| --- | --- | --- |
| 下注 | 红队信息栏在棋盘上方，蓝队信息栏在棋盘下方。各栏显示[实时回报率](../05-settlement/requirement.md)、本人投入、队伍总投、当前建筑和兵种及强化进度。表单显示当前选中的提交队伍 | 选择队伍并填写投入点数后提交。成功刷新余额和累计，并在对应建筑格显示新增兵营或升级。排队确认期间可见等待态，失败后给出原因并保留已确认状态。 |
| 封盘 | 封盘状态、最终的两队配置、有效投入及[锁定回报率](../05-settlement/requirement.md) | 下注入口关闭，查看最终配置。 |
| 战斗回放 | 同一轮棋盘、目前占格数、剩余时间、兵营出兵与战场变化 | 只读观战。可读出哪一方占了哪些格，以及两队当前分数。 |
| 下注结果 | 胜负、最终格数、本人在两队的投入、积分净变化、结算后余额和下一轮倒计时。本人在胜方有投入时显示实际用于入账的锁定倍率。显示胜因，可区分单边主基地被毁、双基地同拍、到时占格、平局及旧版按有效伤害判定 | 自动展示已落账结果。作废显示作废和返还；未参与显示观战结果。 |

建造与升级反馈显示队伍、事件和发生位置。红蓝底色表示当前归属。空置可建格和废墟同样可变色，并保有用于区分的地形样式。比分只统计普通格。下注阶段分别显示本人投入和系统参照投入。阵营已满时，强化进度改为显示已满，提交后提示未新增战力。进入下一轮后，可查看最近完成的一轮结算摘要。

### 建筑生命条

两队存活的基地和兵营在格内上方显示生命条。建成及封盘时显示满条，战斗每半秒按当前帧的建筑生命除以上限更新绿色填充长度。建筑生命上限沿用战斗配置，基地 240、兵营 120。兵营等级改变产出单位的属性，格上生命条始终对应建筑本身。点击建筑可查看当前生命和上限。建筑被毁的当拍切换为废墟并移除血条，结算使用终帧，中途刷新恢复同一帧状态。

### 棋盘上的兵营、兵种与射程

兵营取全名中连续两个字作为简称，部队取其中一个字。兵营格上行显示双字简称，下行常驻显示「1级／2级／3级」，强化成功时立即更新。基地格显示本队开局抽到的种族全称（人族、神族、虫族），跨族建营仍用本队种族。点击基地可读所属队伍、种族、生命（回放中）、本轮攻击属性及本拍命中去向；新规则在地图上高亮基地防守射程并绘制真实命中箭头。建筑被摧毁后显示废墟。两队清单并列显示兵营简称、兵种全名和兵营等级。同一格内以阵营、兵种分别计数，单个省略数量。例如两名蓝方跳虫和一名蓝方机枪兵显示为蓝色「跳2」「枪」。点击格子可查每组全名、数量和配置射程。拥挤格放不下全部分组时，棋盘下方同时列出该格的全部分组与数量。

兵营名称按所属兵种品质着色，由低到高为白、绿、蓝、紫、橙。地面单位表的「金」档显示橙色，普通、无品质或未知品质显示白色。匿名与账号战场、GM 布阵及回放、导入重播的棋盘和对应兵营清单使用同一映射。阵营由格子底色表达，等级和生命维持原标记。

回放按每次实际命中的出手位置、目标位置和攻击方阵营绘制箭头。同格命中用对应阵营的圆环。点选单位格高亮其可攻击距离，混编格按组列出各自射程并高亮其中最大范围。点选兵营可从营格预览其兵种射程。范围按当轮地图距离计算；实际命中还取决于目标、冷却和当拍位置。

## 3. 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 正常下注成功 | 看到对应阵营投入和余额变化，可识别新增／升级的兵营 |
| 提交时恰逢封盘 | 界面转封盘并显示真实确认结果，无法再发起下注 |
| 中途进入回放 | 显示同轮当前棋盘、实时格数和剩余时间 |
| 同格两队或多个兵种 | 各组有独立字标与数量，点击可见全部分组，与回放存活单位逐个对应 |
| 远程兵同一目标进入射程、冷却、命中 | 在实际命中拍看到由出手格指向受击格的连线。点击出手格可比对配置射程与当拍实际攻击距离 |
| 平局或失败 | 结果页的投入、净变化和余额与本轮实际落账一致 |

## 4. 战局复现数据

试玩页的「战局数据」提供「复制当局数据」及「下载当局 JSON」。上一轮有复现数据时，也提供复制和下载上一轮的入口。旧入口提供当局和上一轮快照。完整战局包可从同一浏览器会话的历史中选轮下载。两类文件都由玩家主动导出。

1. 数据记录轮次、开局地图和战斗规则版本、配置时长、当前阶段与相对时间、确认的双边下注、系统投入计划、倍率和阵容。封盘后携带实际快照，有结果时携带赛果和落账。只需提供 JSON 即可复跑战斗。
2. 封盘前导出标记为未封盘，读取时可按当时阵容试跑。之后的投入可能改变最终阵容。
3. 复制成功提示轮次，剪贴板不可用时提示下载。下载由浏览器保存。开发者收到的复现文件可放进工程本地 `battle_data/`，该目录由 Git 忽略。


### 按轮留存与清理

| 数据 | 保存边界 |
| --- | --- |
| bet_log | 本轮请求编号、时间、阵营、金额、是否确认和强化结果。重试不重复扣分或强化。 |
| battle_data | 封盘时固定的阵容、时长、规则、两队投入和倍率。未封盘时完整包仍可导出已发生的下注流水。 |
| battle_log | 开战帧、每拍事件和状态变化、记录截至时点。终局后附胜负和落账。进行中只导出截至当前拍的记录。 |

浏览器内按试玩会话和轮次保存。自动续轮、刷新及重进保留本会话已记录的轮次。确认新建试玩，同步重置余额并清除此会话内的下注、封盘和逐拍记录；取消则保留。过期标签提交时不得写回已结束的会话。旧存档可恢复仍持有的当前轮及上一轮，旧流水无法完整恢复时在导出里标明。已经下载到本机的文件继续由其持有人保管。

## 5. GM 测试与重播

### 测试布阵

棋盘旁的 GM 入口打开独立测试局。布阵时选择红蓝、当前地面兵种和一个亮出的合法可建格，指定生成 1 级兵营。可按位置给营升一级或设 1–3 级。测试兵可放在指定可通行格，含同格多人，按兵种和等级生成满血或指定 1 至最大生命的整数；同格可按对象选择修改生命。主基地和兵营同样可设当前生命。GM 存档独立，不产生竞猜下注、强化进度或积分流水。

封盘生成本次布阵的快照回放，初始显示 0 秒拍。播放、暂停、前进 0.5 秒及原样重开均使用同一初始阵容；刷新恢复所在拍并暂停。返回布阵可只改一项做对照，红蓝镜像交换阵营并将坐标旋转 180 度。点选格子显示对象和该格相关的本拍攻击、目标及目标结算前后生命。单拍多次命中显示每次出手的攻击量及目标本拍合计前后生命。测试局可导出初始快照，包含规则和数值配置版本、种子、稳定出场顺序（两队各自的布阵数组次序）、阵营、位置、等级、起始与最大生命及兵种配置。技能验收按本轮战斗引擎已接入的能力进行。


### 清空棋盘与测试积分

「清空棋盘并新建」确认后清双方测试兵和兵营，恢复默认基地并使用当前规则回到布阵。取消保留阵容及拍位。此操作仅影响 GM 布阵。

从普通竞猜进入 GM，在「试玩测试积分」，输入正整数，确认前显示当前及预计余额。扣至 0 可确认，余额不足或增加后超出安全上限时拒绝。增加后余额与在途下注之和不得超过 90,071,992,547,409 点。同一请求只生效一次，刷新可恢复待确认请求，已切换会话的旧请求被拒绝。调分直接更改本浏览器的普通试玩余额，保留历史结算和同轮下注，且不触发强化。

### 累计日志与胜因

宽屏将累计日志放在棋盘左侧，窄屏放在棋盘与操作之间。播放、单步到某拍时保留从首拍到该拍的日志，向上回看时保留滚动位置，可点「回到最新」。选中格的当拍明细仍可查看。GM 测试局刷新恢复同一拍，重开从首拍开始累计，清盘后从空日志开始。

日志区分计分普通格的占领和可建格、废墟的不计分易手。建筑被拆当拍产生的废墟按拆除记录呈现；胜因随最终比分独立显示，按[胜负规则](../04-battle/requirement.md#4-占格与胜负)认定。比分在末段相同，计时与各拍动作仍按原记录推进。

### 导入指定战局

| 可以导入的文件 | 使用的数据 |
| --- | --- |
| 已封盘 battle_data | 以保存的阵容、棋盘、规则和开火版本重算。 |
| 独立 battle_log | 逐拍播放保存的状态变化。未完日志停在记载的最后一拍，不提前显示赛果。 |
| 完整 bet_data | 优先使用其中的逐拍记录。包含封盘快照时，核对同一轮次及规则，并从快照取冻结兵营资料。只有可用封盘快照时按快照重演。 |

在 GM 进入独立重播页。文件通过格式、版本及关联校验后才切换重播。播放、暂停、0.5 秒单步、回到起点和累计日志使用同一拍号。导入失败保留上一次重播及拍位；刷新后需重新选文件。普通试玩与 GM 布阵不因导入或重播改变。

导入页的存活兵营与普通战场显示同一双字简称、独立等级和当拍生命条。兵营在拆除拍变为废墟，移除原名称、等级和血条。新日志带冻结的兵营名称、坐标、等级和品质。完整包优先取封盘的品质，封盘缺该字段时可用随包日志保存的品质。旧文件缺品质显示白色。旧独立日志仅使用能从记录确认的兵种名，无法确认时显示「兵营」；缺少等级时留空，血量继续读取当拍记录。
