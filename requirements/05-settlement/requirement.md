## 1. 回报率

1. 回报率逐队计算，单位为整数百分比，含本金。两队的队伍总投均包含本人及系统的已确认投入。下注期间，每次有效投入确认后，用更新后的两队总投重新计算双方回报率。
2. 本方总投为 0 时显示「—」。本方有投入时，整数百分数为 `max(110, floor((双方总投之和 × 70 + 2800) ÷ 本方总投))`。队伍总投分别为 350 和 70 时，双方显示 110% 和 460%。
3. 封盘时将最后显示的整数百分数与两队本人实扣一同固定，供本轮回放和结算使用。封盘后的回执补显、刷新和重进均读取原快照。

## 2. 结算时点与对象

回放结束后，使用本轮最终赛果和封盘记录结算测试积分。每个会话同一轮只结算一次，结果与余额同时确认后进入结果阶段。净变化等于落账时加回的积分减去本人本轮对两队的实扣之和。

| 场景 | 落账时加回 |
| --- | --- |
| 红队或蓝队获胜 | `floor(本人在胜方的实扣 × 胜方锁定回报率百分数 ÷ 100)`。败方的投入已在下注时扣除。 |
| 平局或作废 | 退回本人对红蓝双方的全部有效投入。 |
| 未参与 | 0 点。 |

测试示例中，玩家投红 100、投蓝 500，且双方总投等于本人投入，封盘时红蓝回报率为 448% 和 110%。余额从 10,000 降至 9,400。红胜入账 448 点，余额为 9,848。蓝胜入账 550 点，余额为 9,950。平局或作废返还 600 点，余额为 10,000。

## 3. 阶段切换与恢复

1. 玩家中途离开仍按同一赛果结算。刷新和重进时可查看最近一轮的结果与结算后余额。下一轮沿用该余额。
2. 结算记录包含本轮状态、赛果、最终格数（作废可无）、本人对两队的实扣、锁定回报率、入账、净变化及结算后余额。重复读取复用已有记录。
3. 旧试玩记录如已封盘，恢复时仍按当时的固定 200% 结算。已落账结果和余额沿用历史记录。旧会话在下注阶段尚未封盘时，可看到并使用本版本的实时回报率。

## 4. 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 两队总投分别为 350、70 | 对应显示 110%、460%，封盘后保留原值。 |
| 一方总投为 0，另一方总投为 30 | 空队显示「—」，另一方显示 163%；封盘后的有效回执补显不改倍率。 |
| 同轮投红 100、投蓝 500，红胜 | 按胜方锁定倍率计算入账，两队实扣共同计入本轮净变化。 |
| 双边下注后平局或作废 | 返回两边实扣，净变化为 0。 |
| 结果页重复刷新或双标签页同时恢复 | 同轮只入账一次，各次看到的结果和余额一致。 |
