# 里程碑 1 平局判定与战局复现需求分析

反馈来自 #game研讨会 msg=464cfa76，任务 #game研讨会:#23。Danny 定稿战斗 v0.4 和界面 v0.3，独立复核覆盖玩家结算与可复现数据。

| 项目 | 判断及验收边界 |
| --- | --- |
| 平局体验 | 优先比较终局占格，只有格数相同才比较双方有效伤害。有效伤害是被攻击目标实际减少的生命，包括小兵和建筑，同时命中也以目标剩余生命为上限。两项都相同才按平局退两边实扣。 |
| 对局连续性 | 旧对局保持开局规则、棋盘和封盘快照，原回执不重复扣款，下一局启用规则 3。既有胜方倍率、作废与退回口径保持同一套结算。 |
| 复制及下载 | 用户主动在「战局数据」复制或下载当局或上一局。从未封盘到结算字段随状态变化；未封盘明确标记，封盘使用实际阵容，结算含原结果。下载的 JSON 可导入本地重演工具。 |
| 复现数据边界 | 用相对时间、版本、棋盘、投入、倍率和阵容复现，无须传递会话 ID 或请求 ID。调查者可把收到的 JSON 存在 Git 忽略目录 `battle_data/`。 |
