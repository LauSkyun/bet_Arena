# 里程碑 1 格子变色与主基地判胜需求分析

依据 #game研讨会 msg=99358c62 和 v0.5 战斗规则。第 4 局提交的 JSON 是下注第 4.286 秒的临时阵容，封盘阵容与实战终局仍未知。基于该红方阵容补入一个合法的蓝方首营用于复现变色问题。

| 项目 | 验收口径 |
| --- | --- |
| 可走格变色与计分 | 一拍结束后，格上仅有单方存活单位则变为该方颜色。双方同驻或格内为空时沿用原色。普通格、空置可建格和废墟都可以变色，活建筑保持阵营色。比分只数普通格。 |
| 主基地胜负 | 一方主基地被毁就立即冻结战斗、落账并显示结果。两方同一拍都被毁时按该拍占格；到时双方基地都在则按最终占格。两种情况下同格都平局退款。新局取消伤害判胜。 |
| 时间、重演和旧局 | 结算和下一轮从实际结束拍计算，刷新不重复入账，导出的封盘阵容按原规则重演。已有规则 1–3 轮次沿用开局配置；新局规则 4。 |
