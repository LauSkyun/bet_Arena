| 用例 | 环境与实测结果 |
| --- | --- |
| IT22-08-01 公共轮次 | 两个独立 Windows Edge 会话同轮甲红 200、乙蓝 300，公共总投红 300、蓝 400，分别扣至 9,800 和 9,700。冻结阵容、赔率和赛果一致，各按本人实扣计算余额。 |
| IT22-08-02 并发与幂等 | WSL Node 24.22.1 真实 HTTP 和隔离 SQLite。归一化后同账号两端同时押 6,000，只有一单确认；成功与拒绝重试都返回原结果。截止恰点拒绝新单，双端仅记一次账。 |
| IT22-08-03 账户切换 | 1c076db 复现同浏览器切换时旧历史显示甲红 200。新候选跨浏览器同名回到原 UID；同浏览器回原历史标签只显示乙蓝 300，旧甲链接返回 404。 |
| IT22-08-04 历史分页 | 真实 HTTP 结算 22 个本人参与轮，中间跳过观战轮。历史 20 加 2 条，轮号与已结算记录一致。另一个账号仅见本人历史，观战者为空。 |
| IT22-08-05 战局包 | 1c076db 已持久化的拒绝漏进导出。新候选一笔接受及两笔拒绝各保留一次，含时点，系统两笔附实际强化；开战中截至第 0.5 秒。本人历史实际下载并由 Edge 导入 GM，终局一致。用 1c076db 创建真实旧 SQLite 再打开，保留拒绝理由，缺失时点留空并标不完整。 |
| IT22-08-06 断网与重启 | Edge 断网重连后回同轮和余额。停止服务并以同一 SQLite 和端口重开，回读账号及重新下载与旧档一致。 |
| IT22-08-07 匿名入口 | 从隔离浏览器验证 V2.1 统一入口，仍为匿名模式并以 10,000 点开始。 |

隔离测试时钟控制封盘与结算拍；浏览器实际操作登录、下注、断网、跨标签、下载和重播。候选与合并后各过 105 项回归。账号体验与匿名里程碑在各自卡片记录。
