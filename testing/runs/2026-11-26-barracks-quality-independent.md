# 2026-11-26 兵营名称品质色独立验收

#game研讨会:#54 · [棋盘显示需求](../../requirements/06-arena-ui/requirement.md#棋盘上的兵营兵种与射程) · [IT23 XMind](../cases/barracks-quality-2026-11-26.xmind) · [开发自测](2026-11-26-barracks-quality.md)

用独立 Windows Edge 用户目录读取渲染后的颜色。旧匿名 V2.1 的同一 F10 样本包含 14 座营和四档冻结品质，普通战场原先全部显示白色。对候选 c2a9189 和两条集成线分别复核。

| 用例 | 独立实测 |
| --- | --- |
| IT23-06-01 | F10 的同拍普通战场与 GM 完整包逐营对照。14 座营按已存绿、蓝、紫、金映射，金呈橙，阵营由格子底色保留。 |
| IT23-06-02 | GM 为红蓝各布置四档营。在布阵、单步、原样重开和返回布阵复核 8 座营。320 和 390 像素无横向溢出，名称与等级、血条可同时查看。 |
| IT23-06-03 | 旧独立日志无品质字段，14 座营的名称均为白色。新版导出的独立日志保存品质，选文件导入后与封盘品质一致。第 32 局 3-5 在 39.5 秒仍有营，40 秒名称随拆营移除。 |
| IT23-06-04 | 匿名 V2.1 与账号入口使用隔离存储。账号入口的红蓝系统营均为绿色；测试账号实押红蓝各 100 点，测试余额从 10,000 依次到 9,900、9,800，棋盘颜色与服务阵容一致。账号重播页实际导入 F10，逐营与匿名入口同色。 |

合入后的 develop 00b8c58 通过 105 项回归；匿名 V2.1 移植提交 16134d1 通过 101 项，保留匿名入口和现有版本范围。账号检查使用隔离 SQLite。
